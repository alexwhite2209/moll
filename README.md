# Молл Строй — сайт пиломатериалов (Нижний Новгород)

Мобильный сайт склада пиломатериалов: шапка со скролл-роликом «дом разбирается на материалы»,
каталог из 42 товаров и 199 размеров с ценами, калькулятор по всем группам материалов,
отзывы с Яндекс Карт, заказ только звонком — без форм, корзины и регистрации.

## Публикация (GitHub Pages)

Settings → Pages → Source: **Deploy from a branch** → Branch: **main**, папка **/ (root)** → Save.
Через минуту сайт открывается по адресу https://alexwhite2209.github.io/moll/ —
корневой `index.html` сразу перебрасывает на `site/index.html`.

## Как открыть

Статика, без сборки. Любой локальный сервер из папки `site`:

```bash
npx --yes http-server site -p 8125 -c-1
```

Дальше `http://localhost:8125` — главная, `catalog.html` — каталог и цены.

## Где что лежит

| Путь | Что это |
|---|---|
| `site/index.html` | главная: ролик со скроллом, таблички материалов, кольцо категорий, калькулятор, отзывы, контакты |
| `site/catalog.html` | каталог с ценами и калькулятором |
| `site/data/ceny.js` | **цены** — единственный файл для правок, см. `site/КАК-МЕНЯТЬ-ЦЕНЫ.txt` |
| `site/data/catalog.js` | названия, размеры и данные для калькулятора (цены отсюда не берутся) |
| `site/data/content.js` | контакты, отзывы, тексты табличек по сценам |
| `site/js/film.js` | шапка, система как на energy: на компьютере ролик перематывается прокруткой, на телефоне один свайп — следующая табличка, ролик доезжает до своей точки |
| `site/js/countup.js` | цифры-одометр для цен |
| `site/js/gooey.js` | перетекающий текст на табличках |
| `site/js/particles.js` | фон из частиц под тёмными блоками |
| `site/js/app.js` | каталог, кольцо, калькулятор, отзывы; тайминги табличек по кадрам ролика (`TIMING`) |
| `site/assets/film-9x16-intra.mp4` | ролик шапки для телефона: каждый кадр опорный, перемотка мгновенная |
| `site/assets/film-16x9-lite.mp4`, `film-16x9.mp4` | ролик шапки для компьютера: лёгкая ступень сразу, полная догружается |
| `video/prompts.md` | промпты, по которым сделаны ролики (сами мастера в репозиторий не кладём — они лежат локально, в шапке работают файлы из `site/assets`) |
| `audit/index.html` | аудит старого сайта и варианты нового |

## Цены

Меняются в `site/data/ceny.js`: одна строка — один размер, правится только число.
`0` убирает размер из каталога и калькулятора. Дата «цены на …» — в `window.CENY_DATE`.
